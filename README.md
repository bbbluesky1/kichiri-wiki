# キチり大百科

Wikipedia / MediaWiki風の静的サイトです。GitHub Pagesで公開できます。

## ローカルで確認
`index.html` をブラウザで開いてください。

## GitHub Pagesへのデプロイ
1. GitHubで新しいリポジトリを作成します。
2. `index.html`、`style.css`、`script.js` をリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選択し、Branchを `main`、Folderを `/ (root)` にして保存します。
5. 数分後、表示されるGitHub PagesのURLで公開されます。

## 編集
記事本文・目次は `index.html`、デザインは `style.css`、目次の開閉処理は `script.js` を編集してください。

## 補足
現在の版は静的な見た目の再現です。「編集」「ノート」「履歴」は表示用で、MediaWikiのような共同編集・アカウント機能は実装していません。
